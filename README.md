# Johnto

**Johnto** brings Pokémon Gold's Johto adventure into Pokémon Red, Blue, and Yellow using the Gen1Recomp++ engine.

## Features

- Play the original Kanto campaign and the full Pokémon Gold campaign in one save.
- Instantly travel between Kanto and Johto from the START menu.
- Explore all Johto maps plus Gold's post-game Kanto and Mt. Silver.
- Full Gold story, trainers, Gym Leaders, events, dialogue, items, marts, and progression.
- 251 Pokémon with multiple animated and static battle sprite styles.
- Johto Gym Badges and a second Trainer Card badge page.
- Gold field moves including Cut, Fly, Surf, Strength, Flash, Whirlpool, and Waterfall.
- Berry trees, Apricorn trees, Moomoo Farm, slippery ice, boulders, and other Johto mechanics.
- Gold evolutions and HM compatibility adapted to the Gen 1 engine.
- PokéGear with clock, location, and phone contacts.
- Shared party, Pokédex, bag, PC, and save file between both regions.
- Integrated quality-of-life options and cheats.
- Supports Pokémon Red, Blue, and Yellow.

## Install

Extract the mod so you have:

`mods/Johnto/manifest.json`

Enable **Johnto** in the Gen1Recomp++ Mods menu and start a **New Game**.

A Pokémon Gold ROM must be imported in the launcher to play.
